# Solar Bauble
Solar powered flashing Christmas ornament design files and firmware. 
Based on ATTiny85 micro-controller.

Kit available to purchase here:

[https://www.curiouselectric.co.uk/products/solar-bauble-solar-powered-festive-diy-decoration](https://www.curiouselectric.co.uk/products/solar-bauble-solar-powered-festive-diy-decoration)

Files include:

* PCB design files (KiCAD)
* Instructions
* Firmware (Arduino IDE)
